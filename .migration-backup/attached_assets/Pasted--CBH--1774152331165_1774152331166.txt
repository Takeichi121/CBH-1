🚀 คู่มือการติดตั้งโลโก้ CBH สำหรับทุกแพลตฟอร์ม

เพื่อให้โลโก้แสดงผลได้อย่างสมบูรณ์แบบบนทุกอุปกรณ์ (Web, iOS, Android, Windows) ให้ทำตาม 3 ขั้นตอนนี้ครับ

📂 ขั้นตอนที่ 1: สร้างไฟล์รูปภาพ SVG (เซฟไว้ในโฟลเดอร์โปรเจกต์)

คุณเอกจะต้องสร้างไฟล์ 2 ไฟล์นี้ไว้ในโฟลเดอร์เว็บไซต์ (เช่น โฟลเดอร์ /assets/ หรือวางไว้หน้าสุด)

1. cbh-icon-square.svg (แบบสี่เหลี่ยมเต็ม - สำหรับ iOS/Android ให้ระบบตัดขอบเอง)

สร้างไฟล์ใหม่ชื่อ cbh-icon-square.svg แล้วก๊อปปี้โค้ดนี้ไปใส่:

🌐 ขั้นตอนที่ 2: โค้ด HTML สำหรับใส่ใน <head>

นำโค้ดด้านล่างนี้ไปวางไว้ในแท็ก <head> ... </head> ของทุกหน้าเว็บ (หน้า index.html เป็นต้น) โค้ดชุดนี้ครอบคลุมการแสดงผลบน Browser, iOS Home Screen และ Windows Tile แล้วครับ

<!-- แนะนำให้ดึง Font มาเผื่อไว้ด้วย (เพื่อความชัวร์ว่า SVG บนเว็บจะแสดงผลตัวอักษรเป๊ะๆ) -->
<link href="[https://fonts.googleapis.com/css2?family=Montserrat:wght@900&display=swap](https://fonts.googleapis.com/css2?family=Montserrat:wght@900&display=swap)" rel="stylesheet">

<!-- 1. Favicon สำหรับ Browser ทั่วไป (ใช้แบบขอบมน) -->
<link rel="icon" href="cbh-icon-rounded.svg" type="image/svg+xml">
<link rel="icon" href="cbh-icon-rounded.svg" sizes="any">

<!-- 2. Apple Touch Icon สำหรับ iOS / iPadOS (ใช้แบบสี่เหลี่ยมเต็ม ให้ Apple ตัดขอบมนเอง) -->
<link rel="apple-touch-icon" href="cbh-icon-square.svg">

<!-- 3. Web Manifest สำหรับ Android / PWA -->
<link rel="manifest" href="site.webmanifest">

<!-- 4. Theme Color (เปลี่ยนสีแถบด้านบนของ Browser ให้เป็นสีเขียว CBH) -->
<meta name="theme-color" content="#10b981">

<!-- 5. Windows 8/10/11 Tile Color -->
<meta name="msapplication-TileColor" content="#021008">


📱 ขั้นตอนที่ 3: ไฟล์ Manifest สำหรับ Android / PWA

สร้างไฟล์ชื่อ site.webmanifest ไว้ที่หน้าสุดของเว็บไซต์ (Root Directory) ไฟล์นี้จะบอกให้ Android และ Browser รู้จักแอปของคุณเวลาผู้ใช้กด "Add to Home Screen" (เพิ่มลงในหน้าจอหลัก)

{
  "name": "CBH Platform",
  "short_name": "CBH",
  "description": "ระบบจัดการข้อมูลของ CBH",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#021008",
  "theme_color": "#10b981",
  "icons": [
    {
      "src": "cbh-icon-square.svg",
      "sizes": "192x192 512x512",
      "type": "image/svg+xml",
      "purpose": "any"
    },
    {
      "src": "cbh-icon-square.svg",
      "sizes": "192x192 512x512",
      "type": "image/svg+xml",
      "purpose": "maskable"
    }
  ]
}


💡 หมายเหตุ: โค้ดบรรทัดที่เขียนว่า "purpose": "maskable" จะเป็นตัวอนุญาตให้ระบบ Android นำโลโก้แบบจัตุรัสของเรา ไปยัดใส่กรอบวงกลม หรือรูปทรงหยดน้ำ ตามการตั้งค่าเครื่องของผู้ใช้อย่างสวยงาม โดยไม่โดนตัดขอบครับ
