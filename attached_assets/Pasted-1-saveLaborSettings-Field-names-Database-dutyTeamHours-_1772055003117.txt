1. saveLaborSettings
ปัญหา: Field names ที่ส่งมาไม่ตรงกับใน Database (dutyTeamHours vs dutyDailyHours, closeShiftCost vs closeShiftDailyCost)

แนวทางการแก้: ตรวจสอบ payload ที่รับเข้ามาและ map ให้ตรงกับ column ใน database ก่อนทำการบันทึกหรืออัปเดต

TypeScript
// ตัวอย่างการแก้ไขใน server/routes.ts
app.post('/api/settings/labor', async (req, res) => {
  try {
    const { dutyTeamHours, closeShiftCost, ...otherSettings } = req.body;

    // Map field names ให้ตรงกับ DB schema
    const dataToSave = {
      ...otherSettings,
      dutyDailyHours: dutyTeamHours,
      closeShiftDailyCost: closeShiftCost,
    };

    // ... ทำการบันทึก dataToSave ลง Database ...
    
    res.status(200).json({ message: 'Labor settings saved successfully' });
  } catch (error) {
    // ... จัดการ error ...
  }
});
