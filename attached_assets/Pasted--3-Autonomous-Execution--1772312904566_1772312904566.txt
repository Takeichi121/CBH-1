จัดไปครับเจ้านาย! ในเมื่อเจ้านาย "พร้อม" แล้ว เรามาลุย เฟสที่ 3: "มือและเท้า" (Autonomous Execution) ให้จบสมบูรณ์ เพื่อให้ Chann กลายเป็น AI Agent ที่ทำงานและแก้ปัญหาเองได้จริงตามแผนครับ

นี่คือโค้ดชุดสุดท้ายที่จะเชื่อมโยงทุกอย่างเข้าด้วยกัน ตั้งแต่การดึงข้อมูล Aloha (DBF) และ NBO (SQL) ไปจนถึงการรันคำสั่งแก้ไขตัวเอง (Self-Healing) ครับ

📂 1. เตรียมระบบดึงข้อมูล (ก๊อบวางส่วน Service)
ก่อนอื่น ตรวจสอบให้แน่ใจว่าเจ้านายมี 2 ไฟล์นี้เพื่อใช้เป็น "เครื่องมือ" ให้ Chann ครับ:

NBO Service: ใช้รหัส bk1040 เพื่อเข้าถึง SQL Server.

Aloha Service: ใช้อ่านไฟล์ตามเส้นทาง ALOHA_DBF_PATH ที่ตั้งไว้ใน .env.

📂 2. สร้างระบบ Autonomous Agent (ไฟล์: server/services/autonomous-agent.ts)
ไฟล์นี้คือหัวใจที่ Chann จะใช้คิดและเลือกเครื่องมือมาทำงานให้นายครับ

TypeScript
import { exec } from "child_process";
import { promisify } from "util";
import { getNBOSalesAuto } from "./nbo-service";
import { getAlohaSalesRaw } from "./aloha-service";
import { streamLLM } from "../replit_integrations/chat/services/llm-router";
import { pushToBoss } from "../socket";

const execAsync = promisify(exec);

export async function channExecuteTask(taskDescription: string) {
  let currentAttempt = 0;
  const maxRetries = 3;
  let lastError = "";

  while (currentAttempt < maxRetries) {
    console.log(`🤖 Chann กำลังวางแผนงานรอบที่ ${currentAttempt + 1}...`);

    let decision = "";
    // 🧠 AI วิเคราะห์งานและเลือก Tool ที่เหมาะสม
    await streamLLM({
      provider: "openai", // แนะนำ OpenAI สำหรับงาน Logic ซับซ้อน
      mode: "code",
      message: `งานของนายคือ: ${taskDescription}
                เครื่องมือที่มี:
                1. nbo: ดึงยอดจาก SQL (รหัส bk1040)
                2. aloha: อ่านไฟล์ DBF (Path: ${process.env.ALOHA_DBF_PATH})
                3. shell: รันคำสั่ง terminal (ใช้เมื่อจำเป็นเท่านั้น)
                หากรอบก่อนพลาด Error คือ: ${lastError}
                ตอบเป็น JSON เท่านั้น: { "tool": "nbo" | "aloha" | "shell", "command": "string" }`,
      history: [],
      onToken: (t) => { decision += t; }
    });

    try {
      const plan = JSON.parse(decision.replace(/```json|```/g, ""));
      let result;

      // 🛠️ ลงมือทำงาน (Execution)
      if (plan.tool === "nbo") {
        result = await getNBOSalesAuto(); //
      } else if (plan.tool === "aloha") {
        result = await getAlohaSalesRaw(); //
      } else if (plan.tool === "shell") {
        // ⚠️ คำเตือน: exec อาจเป็นอันตรายหาก AI หลอน
        const { stdout } = await execAsync(plan.command, { timeout: 10000 });
        result = stdout;
      }

      // ✅ รายงานผลสำเร็จให้นายทราบผ่าน Socket.io
      pushToBoss("chann-task-complete", {
        message: `สำเร็จแล้วครับนาย! สำหรับงาน: ${taskDescription}`,
        details: result
      });
      return result;

    } catch (error: any) {
      // 🩹 ระบบแก้ไขตัวเอง (Self-Healing)
      lastError = error.message;
      currentAttempt++;
      console.warn(`❌ รอบที่ ${currentAttempt} พลาด กำลังให้ AI วิเคราะห์ Error และแก้ทางใหม่...`);
    }
  }

  // 🚩 รายงานกรณีพยายามจนครบ 3 รอบแล้วยังไม่สำเร็จ
  pushToBoss("chann-alert", {
    title: "⚠️ งานสะดุดครับนาย",
    message: `ผมลองแก้ปัญหา 3 รอบแล้วแต่ยังติด Error: ${lastError} รบกวนนายช่วยตรวจสอบหน่อยครับ`
  });
}
⚠️ ข้อควรระวังสูงสุด (Security Checklist)
เพื่อให้ระบบ "ขั้นสุด" นี้ปลอดภัย เจ้านายต้องตรวจเช็คตามภาพ Final Check ดังนี้ครับ:

จำกัดสิทธิ์ (Sandbox): อย่ารัน Node.js ด้วยสิทธิ์ root เพื่อป้องกัน AI รันคำสั่งอันตราย เช่น rm -rf / โดยไม่ตั้งใจ.

ตรวจสอบ .env: มั่นใจว่า ALOHA_DBF_PATH และรหัส SQL bk1040 ถูกตั้งค่าไว้ถูกต้อง.

Socket.io: ตรวจสอบว่าหน้าจอ Frontend ของนายติดตั้ง socket.io-client เพื่อรอรับเหตุการณ์ chann-alert และ chann-task-complete เรียบร้อยแล้ว.
