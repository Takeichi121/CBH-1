# คู่มือการใช้งานระบบ Borrow Tracker

## ภาพรวม
ระบบ Borrow Tracker ใช้สำหรับติดตามการยืม-คืนอุปกรณ์และวัตถุดิบระหว่างสาขา

---

## 1. หน้า Dashboard (/borrow)

แสดงสรุปข้อมูลรายการยืม-คืน:
- **Total Transactions** - จำนวนรายการทั้งหมด
- **Borrow In** - จำนวนรายการยืมเข้า
- **Borrow Out** - จำนวนรายการยืมออก
- **Recent Activity** - รายการล่าสุด

---

## 2. สร้างรายการใหม่ (/borrow/new)

### ขั้นตอนการสร้างรายการ:

1. **เลือกประเภทรายการ**
   - **Borrow In (ยืมเข้า)** - สาขาเราได้รับของจากสาขาอื่น
   - **Borrow Out (ยืมออก)** - สาขาเราให้ของไปสาขาอื่น

2. **ค้นหาและเลือก Item**
   - พิมพ์ชื่อหรือรหัสสินค้าในช่องค้นหา
   - ใช้ลูกศร ↑↓ เลื่อนเลือก
   - กด Enter หรือคลิกเพื่อเลือก

3. **กำหนดจำนวน**
   - ใส่จำนวนที่ต้องการ
   - กดปุ่ม "Add" เพื่อเพิ่มลงตะกร้า

4. **เลือกสาขา**
   - เลือกสาขาที่เกี่ยวข้องจาก dropdown

5. **กรอกข้อมูลเพิ่มเติม**
   - วันที่ทำรายการ
   - วันครบกำหนด (ถ้ามี)
   - ผู้ยืม / ผู้ให้ยืม
   - หมายเหตุ

6. **ยืนยันรายการ**
   - กดปุ่ม "Submit" เพื่อบันทึก

### การจัดการตะกร้า:
- กด +/- เพื่อเพิ่ม/ลดจำนวน
- เลือก Unit จาก dropdown
- กดไอคอนถังขยะเพื่อลบรายการ

---

## 3. ประวัติรายการ (/borrow/history)

แสดงรายการทั้งหมดพร้อมสถานะ:
- **Pending** - รอดำเนินการ (สีเหลือง)
- **Done** - เสร็จสิ้น (สีเขียว)

### การดำเนินการ:
- **Toggle Status** - คลิกเพื่อเปลี่ยนสถานะ
- **Delete** - ลบรายการ

---

## 4. ตั้งค่าระบบ (/borrow/settings)

เฉพาะ Manager เท่านั้นที่เข้าถึงได้

### 4.1 สาขา (Branches)
- **เพิ่มสาขา** - กรอกชื่อและรหัสสาขา
- **Import Excel** - นำเข้าจากไฟล์ Excel
- **ลบสาขา** - กดไอคอนถังขยะ

### 4.2 รายการอุปกรณ์ (Items)
- **เพิ่มรายการ** - กรอกชื่อ, รหัส และ Units
- **แก้ไข Units** - คลิกที่ช่อง Unit แล้วพิมพ์ (คั่นด้วยจุลภาค)
  - ตัวอย่าง: `BOX, CASE, PACK`
- **Import Excel** - นำเข้าจากไฟล์ Excel
- **ลบรายการ** - กดไอคอนถังขยะ

---

## 6. Units ที่มีให้เลือก

ระบบมี Unit พื้นฐานให้เลือก:
- CASE
- PACK
- CASE PACK
- PCS
- BAG
- TRAY
- CAN
- TANK
- ROLL
- BOX
- GAL
- BTL

สามารถเพิ่ม Unit ใหม่ได้ในหน้า Settings โดยแก้ไขที่ช่อง Unit ของแต่ละ Item

---

## คำถามที่พบบ่อย

**Q: ทำไมเปลี่ยนสถานะไม่ได้?**  
A: ต้อง login เป็น Manager หรือ Admin

**Q: จะเพิ่ม Item ใหม่ได้อย่างไร?**  
A: ไปที่ Settings > Items > กดปุ่ม Add Item

**Q: ค้นหา Item ไม่เจอ?**  
A: ตรวจสอบว่า Item ถูกเพิ่มในระบบแล้วหรือยัง ที่หน้า Settings
