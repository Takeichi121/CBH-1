T001: System Prompt — Explore Phase (ค้นหาก่อนตอบทุกครั้ง)
Blocked By: []
Details:
เพิ่มใน system prompt หลังส่วน [กฎเหล็ก]:
[Explore Phase — ค้นหาก่อนตอบเสมอ]
ก่อนตอบคำถามที่ซับซ้อน ให้ query ข้อมูลที่เกี่ยวข้องก่อนเสมอ โดยไม่ต้องรอให้นายขอ:
- ถามเรื่องกะ/พนักงาน/ยอดขายวันนี้ → ใช้ getCrossSystemSummary ก่อนทันที
- ถามเรื่องไฟล์/โค้ด/CSS/component → ใช้ readSourceFile explore โครงสร้างก่อน อย่าถามว่า path คืออะไร
- ถามเรื่องยืม-คืน → ใช้ getBorrowTransactions + getBorrowBranches พร้อมกัน
- ถามเรื่อง MTD/เดือน → ใช้ getMtdSummary ก่อน
- ไม่รู้ว่าข้อมูลอยู่ที่ไหน → ใช้ getTableRows หรือ readSourceFile สำรวจก่อน แล้วค่อยตอบ
Files: server/routes.ts (บรรทัด ~385-395, ต่อท้ายส่วน [กฎเหล็ก])
T002: System Prompt — Verify Phase (ตรวจสอบหลังเขียนข้อมูลทุกครั้ง)
Blocked By: []
Details:
เพิ่มใน system prompt:
[Verify Phase — ตรวจสอบหลังทำงาน]
หลัง write ข้อมูลทุกครั้ง ให้ read กลับมาตรวจสอบ 1 ครั้งเสมอ:
- หลัง addBorrowTransaction → getBorrowTransactions เพื่อยืนยันว่าบันทึกแล้ว
- หลัง updateStoreSettings → getStoreSettings เพื่อยืนยันค่าที่เปลี่ยน

- รายงานผล verified เท่านั้น เช่น "ตรวจสอบแล้ว: บันทึก X = Y สำเร็จ" ไม่ใช่แค่ "บันทึกสำเร็จ"
Files: server/routes.ts
T003: Agentic Loop — Planning Step (แสดง plan ก่อนทำงาน)
Blocked By: []
Details:
แก้ agentic loop: round แรก (rounds === 1) ให้ส่ง thinking indicator แบบ "กำลังวางแผน..."
เพิ่มใน system prompt: ก่อนเรียก tool ครั้งแรก ให้ระบุใน thinking ว่าจะใช้ tools อะไร เพื่ออะไร
ปัจจุบัน thinking indicator แสดงเฉพาะ round > 1 — แก้ให้แสดง round 1 ด้วย
Files: server/routes.ts บรรทัด ~2090-2093
// แก้จาก:
if (rounds > 1) {
  res.write(`data: ${JSON.stringify({ thinking: `กำลังวิเคราะห์ข้อมูล... (ขั้นตอนที่ ${rounds})` })}\n\n`);
}
// เป็น:
const thinkingMsg = rounds === 1 ? "กำลังวิเคราะห์คำถาม..." : `กำลังประมวลผล... (ขั้นตอนที่ ${rounds})`;
res.write(`data: ${JSON.stringify({ thinking: thinkingMsg })}\n\n`);
